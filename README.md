# Android Launcher

A custom Android launcher focused on fast access, a clean two-column layout, and a visual language inspired by Samsung One UI.

## Status

Early development / project bootstrap.

## Core concepts

- Samsung One UI-inspired visual design
- Persistent date and time on the Home screen
- Favorite apps in two columns
- Collections in two columns
- Application icons always visible
- Numerical notification badges
- Swipe up from Home to open Search
- Search opens immediately with the keyboard focused
- Recently used applications
- Recently searched applications
- No time-based or predictive app recommendations
- Collections displayed as bottom sheets
- Stable and manually ordered Home screen
